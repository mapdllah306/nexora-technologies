# NEXORA Technologies — Website V2

Static bilingual website, ready for GitHub Pages.

## Deploy
1. Open your GitHub repository.
2. Upload `index.html` and `logo.png` to the repository root, replacing the old files.
3. Commit changes to the `main` branch.
4. GitHub Pages will deploy the update automatically if Pages is already configured for `main` / `(root)`.

No build process or API keys required.

Features: Arabic/English, light/dark mode, responsive mobile menu, scroll reveal, interactive logo perspective, scroll progress, reduced-motion accessibility.
